# 샘플 HWPX 정답표 (PRD §11.2)

- [샘플 초기화]는 구성원(지휘관·계획 운용과장·7개 과/중대)만 남기고 모두 지운 뒤, 이 폴더의 샘플 6개를 **추천값 그대로** 아래 순서로 가져와 데이터를 만든다. 원본은 [반영 자료]에 보관된다.
  - 순서: 01 연간 → 04 기타 → 06 회의록 → 02 주간 → 03 8주 → 05 실시사항
  - 가져온 뒤 진행 확인 요청 3건을 붙인다 (`js/seed.js`).
- 문서 날짜는 **2026-11-03(화)** 기준으로 작성했다. 시연 기준일을 이 날짜로 둔다.
- 화면 ③에서 같은 파일을 직접 올리면 "같은 파일을 이미 가져왔습니다"가 나온다. 검토 화면을 보려면 샘플을 고친 뒤 다시 만들거나 다른 파일을 쓴다.
- 아래 표는 2026-11-03 기준으로 브라우저에서 확인한 결과다. 다르게 나오면 맨 아래 기록란에 적는다.

## 05_지난1주일_실시사항 (서술형, 대상 기간 10.26.~11.1.) → 완료 3 · 진행 4 · 실시 기록만 2
판정 규칙: 문장에 **"완료"·"제출"·"보고함"**이 있고 진행 표현(초안·작성 중·검토 중·예정 등)이 없으면 **완료 기록**, 그 밖의 조치 기록은 **진행 기록**이다.
관련 업무가 있으면 완료 기록 → 그 업무 완료, 진행 기록 → 그 업무 진행중(미착수였을 때). 관련 업무가 없으면 실시 기록만 저장한다.

| 문장 | 결과 | 확인 사례 |
|---|---|---|
| 인사과: 신규 전입 장병 면담 3명 실시 | 실시 기록만 (비슷한 업무 없음) | |
| 운용과: 월간 안전점검 **실시** (결과 보고서 작성 예정) | 진행 기록 → "월간 안전점검 결과 보고" 진행중. **완료 안 됨** (경고) | 점검은 했지만 결과보고는 안 한 업무 |
| 3중대: 분기 동원자원 현황 보고서 작성 중 | 진행 기록 → 진행중 (마감 10.28. 지남) | 진행 기록만 있는 업무 |
| 운용과: 정보보호 교육 계획 검토 중 | 진행 기록 → "정보보호 교육" 진행중 | |
| 군수과: 주간 차량 운행 실적 정리 완료 | **완료** (10.30.), 다음 회차 생성 | 실시사항으로 완료 |
| 인사과: 월간 인사 현황 보고 제출 | **완료** (10.30.), 다음 회차 생성 | "제출" |
| 2중대: 월간 장비 가동률 보고 제출 | **완료** (10.31.), 다음 회차 생성 | 마감 지난 업무 완료 |

| 군수과: 예산 집행 현황 점검 | 실시 기록만 | |
