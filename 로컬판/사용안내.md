# 국방이음+ 로컬판 사용 안내

서버·인터넷 없이 PC 한 대에서 쓰는 판입니다. 웹 배포판(kookbang-eum-plus.vercel.app)과 같은 기능을 파일 하나에 담았습니다.

## 들어 있는 것
| 파일 | 내용 |
|---|---|
| `kookbang-eum-plus.html` | 프로그램 전체 (화면·기능·샘플 문서가 모두 이 파일 하나에 들어 있음) |
| `샘플HWPX\` | 문서 가져오기를 시험해 볼 샘플 한글 문서 8개 |
| `사용안내.md` | 이 안내 |

## 실행
1. 폴더를 PC로 복사합니다 (USB·내부 자료 전송 등 부대 반입 절차에 따름).
2. `kookbang-eum-plus.html`을 **더블클릭** → Edge 또는 Chrome에서 열립니다. 설치·관리자 권한·인터넷 연결이 필요 없습니다.
   - 다른 프로그램으로 열리면 파일을 오른쪽 클릭 → [연결 프로그램] → Microsoft Edge.
3. 처음 열면 샘플 데이터가 들어 있습니다. 상단에 **"로컬판 · 이 PC에 저장"**이 보이면 정상입니다.

권장 브라우저: Microsoft Edge 또는 Chrome 최신판 (인터넷 익스플로러는 동작하지 않습니다).

## 실제 업무로 시작하기
⚙ 설정 → **[빈 상태로 시작]** → 구성원(지휘관·계획 운용과장·7개 과/중대)만 남고 모두 지워집니다.
이후 [문서 관리]에서 HWPX 문서를 가져오거나 [업무 추가]·[지시사항 추가]로 입력합니다.

## 데이터는 어디에 저장되나
- 이 PC의 **브라우저 안**(localStorage)에 저장됩니다. 다른 PC와 자동으로 공유되지 않습니다.
- 같은 PC라도 **브라우저가 다르면**(Edge ↔ Chrome) 데이터가 따로입니다. 늘 같은 브라우저로 여세요.
- 브라우저의 **"인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터"**를 하면 지워집니다.
- 저장 공간은 약 5MB입니다. 샘플 전체가 약 0.15MB이며, 큰 HWPX 원본은 보관하지 못할 수 있습니다(그래도 업무 반영은 정상 진행).

## 백업과 다른 PC로 옮기기 (꼭 해 두세요)
⚙ 설정 → **[백업 파일 내보내기]** → `국방이음plus_백업_날짜.json` 파일이 내려받아집니다.
- 업무·실시사항·지시사항·확인 요청·반영 자료 원본이 모두 들어 있습니다.
- 다른 PC: 같은 `kookbang-eum-plus.html`을 열고 ⚙ 설정 → **[백업 파일 가져오기]** → 그 파일 선택.
  가져오면 그 PC의 기존 데이터는 백업 내용으로 **바뀝니다**.
- 주 1회 이상, 그리고 다른 사람에게 넘기기 전에 백업을 받아 두는 것을 권합니다.

## 웹 배포판과 다른 점
| 항목 | 웹 배포판 | 로컬판 |
|---|---|---|
| 실행 | 주소 접속 (인터넷) | 파일 더블클릭 (인터넷 없음) |
| 저장 | Supabase 공유 저장소 (여러 PC가 같은 데이터) | 이 PC 브라우저 |
| PC 간 공유 | 새로고침하면 자동 | 백업 파일로 직접 옮김 |
| 샘플 초기화 | 서버의 샘플 문서 | 파일 안에 든 샘플 문서 |

## 반입 전 확인할 것
- 부대의 **정보보호 규정·반입 승인 절차**를 따르세요. 이 파일은 외부와 통신하지 않습니다(외부 글꼴·라이브러리·CDN 없음, Supabase 주소도 비워 둠).
- 화면의 "가상 데이터"·"교육·시연용" 표시는 시연판 문구입니다. 실제 자료를 다루려면 소속 부대의 보안 담당자와 취급 범위를 먼저 정하세요.

## 문제 해결
| 증상 | 조치 |
|---|---|
| "불러오는 중…"에서 멈춤 | Edge/Chrome으로 열었는지 확인. 인터넷 익스플로러 불가 |
| 데이터가 사라짐 | 다른 브라우저로 열었거나 사이트 데이터가 삭제됨 → 백업 파일 가져오기 |
| "저장 공간이 부족" 안내 | 큰 원본 파일 보관만 생략된 것. 백업 후 오래된 자료 정리 |

## 다시 만들기 (개발용)
웹판 소스를 고친 뒤 프로젝트 폴더에서 아래를 실행하면 이 로컬판이 같은 코드로 다시 만들어집니다.
```
powershell -ExecutionPolicy Bypass -File tools\build-local.ps1
```
